# Context

Glossary for the ATS-optimized resume skill. Terms only, no implementation details.

## Terms

**Tailored Resume**
Resume content rewritten for one specific job. The data a Theme is applied to.

**Theme**
A named visual design for a Tailored Resume. One Theme name gives a matching look in both DOCX and PDF output. Replaces the informal words "preset" and "template".

**Styling**
What a Theme may change: typography, color, spacing, alignment, and section dividers.

**Structure**
What a Theme may never change: column count, text boxes, shapes, and graphics such as skill-rating bars. Structure is fixed so every Theme stays readable by ATS parsers.

**ATS-safe font**
A font common enough on recruiter machines that it will not be substituted. Themes may use only these.

**Theme suggestion**
A Theme the skill proposes from the target industry or job description. The user confirms or overrides it. It is never applied silently.
